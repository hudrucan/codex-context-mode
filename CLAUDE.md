# Contributor guidance

This legacy filename is retained as a pointer for existing tooling. The supported runtime is **Codex only**; it does not enable another host integration.

Read [CONTRIBUTING.md](CONTRIBUTING.md) for architecture, security contracts and validation. Use [configs/codex/AGENTS.md](configs/codex/AGENTS.md) for Codex project routing guidance, without replacing existing project rules.

Use the reviewed local launcher and CLI paths in [README.md](README.md#install). Self-upgrade is disabled; never treat an upstream global package as this fork.

Keep runtime, security, storage, thread isolation and Windows compatibility intact during documentation work. Preserve [LICENSE](LICENSE), upstream attribution and historical ADRs.
